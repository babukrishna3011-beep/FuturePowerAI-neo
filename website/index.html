About the AI

SmolLM2 135M Q4 handles quick everyday interaction. SmolLM2 1.7B Q4 handles deeper mathematics, study and coding. The controller automatically changes the amount of context, decomposition and verification according to the user's device.

For harder work, FuturePowerAIPlus can break a request into smaller steps, retrieve relevant local knowledge, generate an answer, verify it, revise it, and perform an additional secure code-review pass. These techniques improve consistency but do not guarantee perfect results.

Internet access is off by default. When a user explicitly enables it, the app can obtain online reference information and use the online AI endpoint. Conversations and custom backgrounds can remain stored on the user's device.

Model and third-party licensing terms must be preserved with redistributed builds. Educational source files must only be redistributed when legally permitted.
